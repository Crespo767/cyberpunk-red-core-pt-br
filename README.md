# Cyberpunk RED v13 — PT-BR

![Cidade futurista sob chuva, iluminada por luzes vermelhas](src/images/foundry-background-ptbr.png)

Cyberpunk RED no Foundry VTT, com interface e compêndios em português do Brasil. Projeto independente mantido por
[Crespo767](https://github.com/Crespo767), baseado no sistema do Cyberpunk RED Team.

## Requisitos

- **Foundry VTT v13**, build **13.350 ou mais recente da série 13**.
- **[Babele](https://foundryvtt.com/packages/babele)** — obrigatório para traduzir os compêndios.
- **[libWrapper](https://foundryvtt.com/packages/lib-wrapper)** — obrigatório para o funcionamento da tradução pelo Babele.
- **[pt-BR](https://foundryvtt.com/packages/pt-BR)** — recomendado para traduzir os menus e demais elementos da interface do Foundry.
- **[CPR Ficha Alternativa](https://github.com/Kciquehn/cpr-ficha-alternativa)**, de
  [Kciquehn](https://github.com/Kciquehn) — recomendado para usar uma ficha de personagem atualizada e melhorada.
  Instalação opcional pelo [manifesto do módulo](https://github.com/Kciquehn/cpr-ficha-alternativa/releases/latest/download/module.json).

## Instalação

1. Na tela inicial do Foundry, acesse **Sistemas de Jogo → Instalar Sistema**.
2. Cole esta URL no campo **URL do Manifesto** e instale:

   ```text
   https://github.com/Crespo767/cyberpunk-red-core-pt-br/releases/latest/download/system.json
   ```

3. Aceite a instalação das dependências **Babele** e **libWrapper**.
4. Crie ou abra um mundo com o sistema **Cyberpunk RED v13 - PTBR**.
5. No mundo, acesse **Configurações → Gerenciar Módulos** e ative **Babele**, **libWrapper** e os módulos recomendados que tiver instalado.
6. Nas configurações do Foundry, selecione **Português (Brasil)** como idioma e recarregue o mundo quando solicitado.

As atualizações são feitas pelo gerenciador de sistemas do Foundry. Os downloads e as notas de cada versão ficam nos
[Releases](https://github.com/Crespo767/cyberpunk-red-core-pt-br/releases).
